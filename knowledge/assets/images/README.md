# Curated image assets

This directory stores offline, curated visual references for Knowledge Base
documents. These images are separate from private user journal photos.

## Structure

```text
grape/
  stages/<stage-id>.webp
  threats/<target-id>/<subject>.webp
```

The twelve current grape stage images use the stable stage-ID suffix as their
filename. Threat images use a target-ID directory so one target can have several
reference views, such as a leaf, cluster, or insect close-up.

## Current status

The files are organized source assets only. They are not yet referenced by an
authored Knowledge Base document, schema, compiler output, or mobile screen.
Before linking an image to the application, record its source, licence,
attribution requirement, Vietnamese alt text, and review status in the future
Knowledge Base image-asset contract. A threat image remains observation context;
it must not imply diagnosis, spraying eligibility, or treatment.
